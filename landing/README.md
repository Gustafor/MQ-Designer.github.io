# RabbitMQ Designer Course — прототип лендинга

Astro-прототип главной страницы курса в стиле Karpov.Courses: тёмная база `#1E2027`, акцент `#FF5533`, крупная uppercase-типографика, сетка карточек, три тарифа.

## Запуск

```powershell
cd site
npm.cmd install
npm.cmd run dev
```

Откройте `http://localhost:4321/`.

Сборка:

```powershell
npm.cmd run build
npm.cmd run preview
```

## Структура

- `src/pages/index.astro` — главная.
- `src/pages/ui.astro` — UI-кит: токены, кнопки, карточки, форма, схема.
- `src/pages/program.astro` — программа.
- `src/pages/corporate.astro` — корпоративный формат.
- `src/pages/free.astro` — бесплатный чек-лист.
- `src/pages/tools.astro` — страница среды RabbitMQ Designer.
- `src/pages/thanks.astro` — экран после заявки.
- `src/pages/legal/` — шаблоны политики ПДн и оферты.
- `src/components/` — секции и UI-компоненты.
- `src/data/course.ts` — контент, тарифы, программа, FAQ, отзывы.
- `src/styles/` — токены и глобальные стили.

## Что работает в прототипе

- Sticky-шапка, мобильное меню, активная навигация по секциям.
- Аккордеоны программы и FAQ (нативный `<details>`).
- Демо-форма: валидация и success-состояние без отправки на сервер.
- Анимации появления с `prefers-reduced-motion`.
- Мобильная нижняя CTA-панель появляется после скролла.
- Адаптив: 1440 / 1024 / 390.

## Что заменить перед запуском

- `public/images/author.png` — временный публичный GitHub-аватар. Нужен реальный author cutout 3:4.
- `public/screenshots/designer.png` — реальный скриншот среды; обновить после изменений UI.
- Контакты, домен, реквизиты, политика ПДн и оферта — сейчас заглушки.
- Демо-форму подключить к GetCourse / CRM, добавить антиспам и согласие.
- Тарифы и даты — гипотезы, заменить после интервью.
- Отзывы — обезличенные отзывы пилота; добавить имена и компании только с согласия.
- Цены и обещания — не добавлять гарантии трудоустройства или зарплаты.
